Generating… this can take 1–4 minutes (texture first, then the 3D mesh).

Two on-prem models work together: Qwen-Image-Edit converts your reference photo into a full PBR material set — albedo, height, normal, roughness, metallic. Hunyuan3D-2.1 then generates a real textured 3D mesh from the same image (~2–4 min at high detail); if it is unavailable, a 2.5D relief mesh (silhouette + depth) is used instead. "Build 3D from the image" is on by default, so the preview shows the object derived from your photo — uncheck it to preview the preset shape instead.
