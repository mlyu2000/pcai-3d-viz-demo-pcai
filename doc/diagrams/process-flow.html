Process Flow — the Artist's Journey (end to end)

Screenshots are from the live deployment on CS1 (viz-demo.aie.cs1.ctc.sg.lab), real run: cup sample → real-3D GLB. Every step below is a real screen or artifact.

STEP 1
Pick a reference
Drop a photo, paste a URL, or pick a bundled sample (Car / Cup / Hat). Optionally set strength, seed, and tick “Build 3D from the image”.
Studio tab: reference dropzone + sample library + Build-3D toggle.
upload / URL / sample
→
STEP 2
Generate textures
Click Generate. Qwen-Image-Edit turns the photo into a clean albedo; the backend derives the full PBR set (height / normal / roughness / metallic) + runs quality gates.
Real albedo.png from the live run (1024×816).
albedo height +normal/rough/metal
→
STEP 3
Build real 3D
With “Build 3D” on, Hunyuan3D-2.1 generates a true textured mesh (GLB) on the A100 (~3–4 min). If the GPU is busy it transparently falls back to a 2.5D CPU relief — the flow never dead-ends.
Result: albedo + height thumbnails + live textured 3D cup; badges model & Real 3D · hunyuan3d-2.1.
GLB (real) 2.5D fallback
→
STEP 4
Save to library
Name & tag it, hit Save. The asset lands in the shared Library (persistent NFS PVC) — browse, search, reload into preview, or open later.
Library grid — every asset with Maps / Blender-pack / Load buttons.
persistent search / tag
→
STEP 5
Into Blender
Tier 1: download maps / the Blender-pack / a ready .blend → opens in the artist's own Blender with full PBR. Tier 2: type a natural-language prompt → the LLM writes & runs Blender code.
Tier 1 — the same cup rendered in real Blender from the pack.
Tier 2 — a low-poly car built live by the LLM (6 objects, 1st attempt).
Tier 1 pack .blend Tier 2 LLM
Loops & quality gates (behind the scenes): if the albedo fails a quality gate the backend re-generates up to 2×; a reused asset is self-healed (a stale 2.5D asset is upgraded to real 3D on the next “Build 3D”). Idempotent: the same photo → the same content-hash asset ID, so re-running returns the cached result instantly.
Tier 2 note: the AI Model Box runs entirely on the artist's machine — it calls the existing CS1 LLM directly (scoped virtual key + private CA), never the app pod.
